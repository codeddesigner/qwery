# Qwery — forms that start conversations

Built from the Qwery Figma file (Foundations, Components, Screens). React 19 SPA bundled with esbuild, Supabase (auth, Postgres + RLS, storage, pg_net webhooks) and Vercel functions (`/api`) for AI (Vercel AI Gateway), brand detection, Google Forms import and link previews.

- `npm install && npm run build` → `dist/`
- Typeface: Calamantus (self-hosted in `public/fonts`).
